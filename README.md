# LittlePotato Skill

LittlePotato 的个人 Claude Code 技能库。

## 技能目录

### Learning

| 技能 | 说明 |
|------|------|
| [lp-tidy-any-text](./learning/lp-tidy-any-text/) | 将任意学科的杂乱复习资料整理成结构化复习文件 |

### Competition Docs

| 技能 | 说明 |
|------|------|
| [lp-md2docx](./competition-docs/lp-md2docx/) | 将 Markdown + 图片文件夹转换为带样式表和多级标题的 Word 文档（比赛文档专用） |
| [lp-competition-proposal](./competition-docs/lp-competition-proposal/) | 根据代码与材料分阶段生成比赛项目计划书（文字稿→图片映射表→调研补全→最终 .md） |

## 安装

将技能文件夹复制到以下路径：

**个人全局**（所有项目可用）：
```
~/.claude/skills/<skill-name>/
```

**单项目**（仅当前项目可用）：
```
<项目>/.claude/skills/<skill-name>/
```
