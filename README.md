# LittlePotato Skill

LittlePotato 的个人 Claude Code 技能库。

## 技能目录

| 技能 | 说明 |
|------|------|
| [lp-tidy-any-text](./lp-tidy-any-text/) | 将任意学科的杂乱复习资料整理成结构化复习文件 |

## 安装

将技能文件夹复制到以下路径：

**个人全局**（所有项目可用）：
```
~/.claude/skills/<skill-name>/
```

**单项目**（仅当前项目可用）：
```
<项目>/.claude/skills/<skill-name>/
```
