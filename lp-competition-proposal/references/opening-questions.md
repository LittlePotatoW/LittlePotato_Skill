# 开场问卷与材料清单

阶段 0 一次性问齐，避免反复打断用户。按顺序提问，回答后汇总成《材料清单》让用户确认。

## 必问四项

### 1. 有什么材料

- 代码文件夹路径（本地目录）
- 项目计划书要求：评分标准 / 格式要求 / 章节要求（文件或粘贴文字均可）
- 已有草稿：是否已有 .md / Word / 零散文档
- 比赛背景材料：比赛通知、往届获奖作品、官网 / 白皮书 / 新闻（可给链接或文件）
- 其他：数据、访谈记录、测试报告、用户反馈

### 2. 能提供什么

- 图片：界面截图、架构图、流程图、Logo、实物照片等（说明大概有哪些）
- 数据：用户量、测试数据、调研数据
- 人力信息：团队成员与分工（实施计划章节需要）

### 3. 需要做到哪一步

- A：纯文字稿 + 图片需求清单
- B：收集图片后生成正式版 .md
- C：调研补全成最终 .md（竞品分析 / 背景 / 意义等）
- D：最终 .md + 转 Word（衔接 lp-md2docx）

### 4. 比赛类型

- 计算机设计大赛（技术文档，重架构 / 实现 / 测试）
- 互联网+ / 挑战杯（商业计划书，重市场 / 商业模式 / 财务）
- 其他：请用户说明评分标准，以评分标准为准

把回答整理成表格，请用户确认后才开始：

| 已有草稿 | ... | ... |
| 背景材料 | ... | ... |
| 图片 | ... | ... |
| 目标步骤 | A / B / C / D | 待确认 |

用户确认后进入阶段 1（出方案）。
