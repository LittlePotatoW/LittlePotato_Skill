# LP_TidyAnyText

将任意学科的杂乱复习资料整理成结构化复习文件。

## 安装

复制此文件夹到：

**个人全局**：
```
~/.claude/skills/lp-tidy-any-text/
```

**单项目**：
```
<项目>/.claude/skills/lp-tidy-any-text/
```

## 使用

### 直接调用

```
/lp-tidy-any-text 帮我整理[学科]复习资料
```

### 工作流程

1. **AI 扫描** → 检查工作区源文件和已有内容
2. **AI 生成 `rule.md`** → 包含自动识别的信息和需要你填写的项目
3. **你回复"继续"** → AI 按 rule.md 开始整理
4. **六步流程**：环境准备 → 文件转化 → 课程调研 → 按章整理 → 错误检查 → 最终输出

### 你需要准备的

- 源文件（PDF、DOCX、DOC、XMIND、图片等），放在工作区即可
- 收到 AI 生成的 `rule.md` 后，填写/修改需要的内容（未填的 AI 会自动补全）

## 核心特性

- 适用任何学科，不限专业
- 先确认规则再干活，不会瞎整理
- 判断题每个错误选项都会解释原因
- 修正信息小号字体标注
- 所有下载放工作区，不污染系统盘
- 提供默认输出模板，也支持自定义
