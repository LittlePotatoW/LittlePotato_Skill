## 七、默认规则（AI 默认行为，如与你上面填写的冲突，以你填写的为准）

### 章节整理规则
- 保证准确性，保证关键词完整性，不丢失信息
- 重点内容用**加粗**标注
- 去重：去掉相同的内容
- 跨来源交叉验证

### 题目整理规则

**选择题：**
- 题目、选项、答案写在一起
- 无解析的题目必须补上解析
- 格式：
  ```
  **1. 题目内容？**
  A. 选项A  B. 选项B  C. 选项C  D. 选项D
  **答案：X**
  解析：说明为什么选X。
  ```

**判断题：**
- 题目和答案写在一起
- **每个答案为"错误"的判断题，必须说明原因**（指出题目中哪部分表述有误、正确的表述应是什么）
- 格式：
  ```
  **1. 题目内容。（判断正误）**
  **答案：错误（×）**
  原因：题目中"XXX"表述有误，正确的是"YYY"。
  ```

**课后思考题：**
- 题目和答案写在一起

### 错误修正与时效性标注
- 检查答案是否有疑似错误，有则搜集资料确认
- 修正内容用小号字体附在后面：
  `<small>（修正：原答案为X，经查证正确应为Y）</small>`
- 时效性问题用小号字体标注：
  `<small>（时效提示：该数据已过时，最新为XXX）</small>`
