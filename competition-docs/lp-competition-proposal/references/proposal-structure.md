# 计划书章节骨架

## 通用骨架（比赛项目文档）

| 章节 | 内容 | 主要来源 |
|------|------|----------|
| 1 项目概述 | 背景、目标、意义 | 调研 + 用户 |
| 2 市场与用户分析 | 用户画像、需求痛点、竞品分析 | 调研 |
| 3 项目内容与方案 | 总体设计、功能模块、技术方案、系统架构 | 代码分析 |
| 4 创新点与特色 | 差异化、技术亮点 | 代码 + 调研 |
| 5 实施计划 | 进度安排、团队分工 | 用户材料 |
| 6 可行性分析 | 技术、经济、风险 | 代码 + 调研 |
| 7 预期成果与效益 | 成果、社会 / 经济效益 | 调研 + 用户 |
| 8 附录 | 图表索引、参考文献 | 汇总 |

## 常见比赛变体

### 计算机设计大赛（项目文档）

侧重：需求分析、系统架构、功能实现、技术难点、测试与部署。
图片必需：架构图、功能模块图、界面截图、数据库 ER 图、部署图。

### 互联网+ / 挑战杯（商业计划书）

侧重：市场分析、商业模式、财务预测、团队。
图片必需：Logo、产品界面、商业模式图；竞品对比用表格代替图片。

### 课程 / 毕业设计（论文格式）

侧重：研究意义、相关工作、方法、实验、结论。
图片必需：实验截图、数据图表、流程图。

## 使用方式

- 用户提供的计划书要求（评分标准）优先于本骨架，按它调整章节
- 阶段 1 输出《方案.md》：章节表 + 每章内容来源 + 图片清单，等用户确认
