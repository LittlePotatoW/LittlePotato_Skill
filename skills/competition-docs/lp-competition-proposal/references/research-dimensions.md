# 调研维度与输出格式

用于调研块（阶段 2）：补全论文引用、应用场景、竞品分析、市场与用户需求等。

## 调研块通用规则

- **双文件留痕**：原始材料 → `调研过程/<块名>/原始笔记.md`（带链接、带过程、可含截图说明）；
  正式结论 → 工作区根文件 `NN-调研-*.md`
- 每节 300~500 字 + 必要表格
- 所有事实性结论标注来源（来源名 + 年份 / 链接）
- 找不到依据的结论标注"待确认"，不得编造数据
- 材料不足时：列出缺口清单询问用户，补充后再写

## 论文引用

- 检索导师 / 课题组相关论文（作者、机构、方向）
- 按 GB/T 7714 格式整理：`[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 页码.`
- 标注每篇文献的"使用场景"（项目背景 / 技术方案 / 创新点 / 团队背书）
- 期刊全名、卷期页码不确定时标"待确认"

## 应用场景（地区 / 行业）

- 政策与战略：相关文件（标注文号 / 年份）、地区战略落位（如"五大安全"）
- 场景清单：每个场景配数据（项目规模、采购实例、监管基数）与需求落点
- 场景 → 产品功能一一对应

## 竞品分析

- 竞品清单：3~5 个（软件类直接竞品 + 硬件类替代品分开列）
- 对比维度：功能、价格、适用场景、优劣势、与本项目差异
- 输出对比表 + 每个竞品 1 段分析

| 竞品 | 类型 | 功能 | 价格 | 优势 | 劣势 | 与本项目差异 |
|------|------|------|------|------|------|--------------|

- 价格锚点：政府采购 / 厂商报价等真实价格优先，无则标"待确认"

## 市场与用户需求

- 目标用户画像：人群、场景、特征、采购特征
- 需求痛点：3~5 条，每条配数据或材料依据
- 市场规模：优先引用权威来源（白皮书 / 研报 / 官网），无数据标注"待确认"

## 多口径数据统一

同一指标出现多个口径时（不同机构、不同统计范围）：

1. 全部记录在原始笔记中，不丢弃
2. 正式文件中选一个**主口径**（优先权威 / 官方 / 最新），其余作为**辅助口径**列出
3. 每个口径注明来源与年份，**不混用、不取平均**
4. 示例：中国辐射检测仪市场主口径"约 98.6 亿元（GEP 2026）"、
   辅助口径"含软件与服务超 120 亿元（华信人 2026）"

## 数据缺口与待确认项

每个调研文件末尾设固定章节：

- 列出所有缺口（缺省级数据、缺官方公报核实、缺付费报告验证等）
- 列出待确认项（口径选择、价格、下载量、合作单位等）
- 涉及用户才能提供的信息（合作意向、真实数据）单独标记
