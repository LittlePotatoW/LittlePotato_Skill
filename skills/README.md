# Skills

| 技能 | 分类 | 说明 |
|------|------|------|
| [lp-tidy-any-text](./learning/lp-tidy-any-text/) | learning | 将杂乱复习资料整理成结构化复习文件 |
| [lp-md2docx](./competition-docs/lp-md2docx/) | competition-docs | Markdown + 图片文件夹转带样式表和多级标题的 Word 文档 |
| [lp-competition-proposal](./competition-docs/lp-competition-proposal/) | competition-docs | 分阶段生成比赛项目计划书（文字稿→图片映射→调研补全→最终 .md） |
