# lp-build-orchestrator

为非平凡软件构建任务提供按需并行协作流程。`lp01`、`lp02`、`lp03` 是当前配置的通用 Codex 子代理示例，可承担调研、简单代码实现、代码审查、测试或验证；它们不限定代理数量。主代理可根据任务决定启动数量，或按用户指定数量分派独立工作。

## 安装

个人全局安装到 `~/.codex/skills/lp-build-orchestrator/`，项目级安装到 `<项目>/.codex/skills/lp-build-orchestrator/`。代理配置可放在全局 `~/.codex/agents/` 或项目级 `<项目>/.codex/agents/`；需要更多自定义代理时按需增加配置。

## 使用

自动匹配多文件或复杂软件构建任务，也可显式调用 `$lp-build-orchestrator`。简单任务由主代理直接完成；并行任务由主代理决定代理数量，或遵循用户指定数量，再把独立任务分给可用代理。

## 状态

仓库内维护；代理调用能力取决于当前 Codex 环境对项目级自定义代理的支持。
